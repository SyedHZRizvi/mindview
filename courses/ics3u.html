Chapters

Chapter 1
Unit 1: Introduction to Programming
First Python programs, variables, primitive data types, arithmetic, input/output, console interaction, code style and commenting
Chapter 2
Unit 2: Control Flow & Logic
Comparison & logical operators, if/elif/else, while and for loops, nested constructs, Boolean expressions
Chapter 3
Unit 3: Modular Programming & Data Structures
Functions, parameters & return values, variable scope, 1-D lists/arrays, strings as sequences, simple algorithms
Chapter 4
Unit 4: Software Development Process
Problem-solving, IPO charts, pseudocode, debugging strategies, test cases, documentation, sequential file I/O
Chapter 5
Unit 5: Computer Environments & Society
Hardware/software, operating systems, networking basics, ethics, privacy, cybersecurity, careers and education pathways
