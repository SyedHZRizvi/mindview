Part A: Knowledge & Understanding [15 marks]
1. [3 marks]
List the six stages of the software-development process in order.
2. [3 marks]
Classify each as syntax, runtime, or logic error.
  1. for i in range(10) # missing colon
  2. print(1 / 0)
  3. A function that should sum 1..n but actually sums 1..(n-1)
  4. int("hello")
  5. print x (no parentheses)
3. [3 marks]
Explain in one sentence each:
  1. What an IPO chart is for.
  2. What pseudocode is.
  3. Why we put planning before coding.
4. [3 marks]
Describe the difference between mode "w" and mode "a" in open. Give one situation where each is appropriate.
5. [3 marks]
Define each in one sentence:
  • Boundary case (in testing)
  • Regression test
  • Header comment
Part B: Thinking & Investigation [15 marks]
6. [5 marks]
Translate this pseudocode into valid Python.
SET total = 0 SET count = 0 WHILE more input: READ mark IF mark >= 0: ADD mark to total ADD 1 to count SET average = total / count PRINT average
You may use any reasonable sentinel for "more input".
7. [5 marks]
Find and fix the bugs. This program should write each of nums on its own line in out.txt. There are at least three bugs. Rewrite it correctly.
nums = [10, 20, 30] f = open("out.txt", "r") for n in nums f.write(n) f.close
8. [5 marks]
Design a test plan with at least five distinct test cases (input and expected output) for a function letter_grade(percent) that maps a percent (0-100) to Ontario achievement levels: Level 4 (80+), Level 3 (70-79), Level 2 (60-69), Level 1 (50-59), R (<50). Cover normal, boundary, and invalid cases.
Part C: Communication [15 marks]
9. [5 marks]
Build an IPO chart for the following problem: "Read student names and marks from a CSV file. Print the names of all students who scored above the class average." Show three columns.
10. [5 marks]
Add a header comment, a docstring, and clear inline comments to this program so a future reader understands it. You may also rename variables.
def x(a,b): t=0 with open(a) as f: for L in f: t+=int(L.strip()) with open(b,"w") as g: g.write(str(t))
11. [5 marks]
A classmate insists that "testing is a waste of time — if the code looks right, it works". In 4-6 sentences, respectfully explain why testing is important, drawing on concepts from this unit.
Part D: Application [15 marks]
12. [5 marks]
Write a complete Python program that asks the user for a filename, then reads that file and prints the number of lines, the number of words (whitespace-separated tokens), and the number of characters. Use the with idiom.
13. [5 marks]
Write a program that appends a line to a log file called diary.txt every time it is run. Each line should contain the date in the format YYYY-MM-DD followed by a user-typed message. Use the datetime module for the date.
14. [5 marks]
A CSV file marks.csv has lines of the form name,mark:
Ada,85 Bob,72 Cay,91 Dee,64
Write a complete program that reads this file and prints:
  • The number of students.
  • The class average (1 decimal).
  • The name of the highest-scoring student.
