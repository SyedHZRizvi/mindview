Part A: Knowledge & Understanding [15 marks]
1. [3 marks]
Trace the calls and give the output of each:
def double(x): return 2 * x print(double(5)) print(double(double(3))) print(double("hi"))
2. [3 marks]
Predict the values.
nums = [10, 20, 30, 40, 50] print(nums[0]) print(nums[-2]) print(nums[1:4]) print(len(nums)) print(sum(nums))
3. [3 marks]
What is printed?
def f(a, b=10): return a + b print(f(5)) print(f(5, 20)) print(f(b=3, a=2))
4. [3 marks]
For each string operation, give the result.
s = "Hello World" print(len(s)) print(s.lower()) print(s.replace("World", "ICS3U")) print(s.split())
5. [3 marks]
Explain in one sentence each:
  1. The difference between a parameter and an argument.
  2. What "local variable" means.
  3. Why Python returns None from a function with no return.
Part B: Thinking & Investigation [15 marks]
6. [5 marks]
Find and fix the bugs. This function should return the average of a list of numbers. There are three bugs. Rewrite it correctly.
def average(nums) total = 0 for n in nums: total = n # BUG return total / len(nums
7. [5 marks]
Trace this program carefully and state the output.
def update(lst, item): lst.append(item) return lst a = [1, 2] b = update(a, 3) b = update(b, 4) print(a) print(b) print(a is b)
8. [5 marks]
Write a function count_vowels(s) that returns the number of vowels (a, e, i, o, u, case-insensitive) in a string. Show count_vowels("Programming") at the bottom with the expected result.
Part C: Communication [15 marks]
9. [5 marks]
A peer has written one giant function that reads marks, computes the average, finds the highest, and prints a report — all in 25 lines with one-letter variable names. List five specific style/quality issues you would raise in a code review and explain why each matters.
10. [5 marks]
Rewrite the function with meaningful names, a docstring, and at least two inline comments.
def f(L): t=0 for x in L: t+=x return t/len(L)
11. [5 marks]
Explain in a short paragraph (3-5 sentences) why functions matter in programming. Use at least two of: reuse, abstraction, decomposition, testing, naming.
Part D: Application [15 marks]
12. [5 marks]
Write a function longest_word(sentence) that returns the longest word in a sentence (a string). Words are separated by spaces. If two words tie, return either one. Demonstrate it on the input "the quick brown fox jumped over the lazy dog".
13. [5 marks]
Write a complete program that:
  1. Asks the user how many marks they will enter.
  2. Reads that many marks into a list.
  3. Calls helper functions average(nums) and highest(nums) that you also define.
  4. Prints the average (1 decimal) and the highest.
14. [5 marks]
Write a function initials(full_name) that takes a string like "Ada Lovelace" and returns the initials joined by periods: "A.L.". Trailing period required. Make sure it works for any number of words. Demonstrate on two example calls.
