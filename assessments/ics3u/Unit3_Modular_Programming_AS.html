Question 1 — Function output
What does this print?
def square(x): return x * x print(square(7))
Solution:
square(7) returns 7 * 7 = 49. print shows 49.
Question 2 — return vs print
What does x contain afterwards?
def greet(name): print("Hello", name) x = greet("Ada") print(x)
Solution:
The function prints, but does NOT return anything. Python implicitly returns None, so x = None. Output: "Hello Ada" then None.
Question 3 — List indexing
What is the value of scores[-1] when scores = [80, 75, 92, 67]?
Solution:
Negative indices count from the end. scores[-1] is the last element: 67.
Question 4 — List slicing
What is nums[1:4] when nums = [10, 20, 30, 40, 50]?
Solution:
Slice [start:stop] is start-inclusive, stop-exclusive. Indices 1, 2, 3 are 20, 30, 40. Answer: [20, 30, 40].
Question 5 — Local vs global
What is printed?
x = 100 def f(): x = 5 print(x) f() print(x)
Solution:
Inside f, the assignment x = 5 creates a LOCAL x, separate from the global. Prints 5 inside, then 100 outside.
Question 6 — List append
After nums = [1, 2]; nums.append(3); print(nums), what is shown?
Solution:
.append(3) adds 3 to the end. Output: [1, 2, 3].
Question 7 — String method
What does "Hello World".lower().split() return?
Solution:
.lower() returns "hello world", then .split() with no argument splits on whitespace. Result: ['hello', 'world'].
Question 8 — Default parameter
What does greet("Bob") return?
def greet(name, greeting="Hello"): return f"{greeting}, {name}!"
Solution:
Because no second argument is passed, greeting takes its default value "Hello". Returns Hello, Bob!.
Question 9 — Aliasing trap
What is printed?
a = [1, 2, 3] b = a b.append(4) print(a)
Solution:
b = a does NOT copy — both names refer to the same list. b.append(4) modifies the shared list, so a sees the change too: [1, 2, 3, 4].
Question 10 — Multiple return
What is printed?
def stats(nums): return min(nums), max(nums) lo, hi = stats([4, 9, 1, 6, 3]) print(lo, hi)
Solution:
The function returns a tuple (1, 9). Unpacking sets lo=1, hi=9. Printed: 1 9.
Question 11 — Write a function body
Complete the function. (Type the missing single line.)
def is_even(n): ______________________
Solution:
return n % 2 == 0. The function returns True if n is even, False otherwise.
Question 12 — List length
What does len([1, [2, 3], 4, 5]) return?
Solution:
The list has 4 top-level elements: 1, the sublist [2, 3], 4, and 5. len counts top-level elements only: 4.
