Part A: Knowledge & Understanding [15 marks]
1. [3 marks]
State the value of each Boolean expression.
  1. (7 > 3) and (4 < 2)
  2. (7 > 3) or (4 < 2)
  3. not (5 == 5)
  4. 1 < 4 < 10
2. [3 marks]
Trace this program. What is printed?
x = 3 if x > 0: if x > 5: print("big") else: print("small positive") else: print("zero or negative")
3. [3 marks]
Trace this loop. What does it print?
i = 1 while i <= 5: print(i, end=" ") i += 2
4. [3 marks]
Write an if/elif chain that prints "Child" if age < 13, "Teen" if 13-19, "Adult" if 20-64, otherwise "Senior".
5. [3 marks]
What is the output of this nested loop?
for i in range(3): for j in range(2): print(i, j)
Part B: Thinking & Investigation [15 marks]
6. [5 marks]
Find and fix the bugs. This function should return the sum of even numbers from 1 to n inclusive. There are three bugs. Rewrite it correctly.
def sum_evens(n): total = 1 for i in range(0, n): if i % 2 = 0: total + i return Total
7. [5 marks]
Trace the following nested-loop program. List every line that print outputs, in order.
for i in range(3): for j in range(3): if i == j: print(f"({i},{j}) diagonal") elif i < j: print(f"({i},{j}) above") else: print(f"({i},{j}) below")
8. [5 marks]
Write a Python program that asks the user to enter integers one at a time. The program stops when the user enters 0, then prints (a) how many positive numbers were entered and (b) how many negative numbers were entered.
Part C: Communication [15 marks]
9. [5 marks]
Explain in your own words the difference between a for loop and a while loop. Include when each is most appropriate, what risks each has, and a one-line example of each.
10. [5 marks]
Below is a peer's check meant to test if x is one of 1, 2, or 3. List the specific bug and write a correct version. Briefly explain why the bug exists (what Python actually evaluates).
if x == 1 or 2 or 3: print("ok")
11. [5 marks]
Use De Morgan's laws to rewrite each expression so that not applies only to a single comparison (not a compound). Show your work.
  1. not (a > 0 and b > 0)
  2. not (x == 5 or y == 5)
Part D: Application [15 marks]
12. [5 marks]
Write a complete Python program that:
  1. Asks the user for their hourly wage and the number of hours worked this week.
  2. Pays regular pay for the first 40 hours and time-and-a-half (1.5×) for hours over 40.
  3. Prints the total formatted to two decimal places.
If hours or wage is negative, print an error and stop.
13. [5 marks]
Write a Python program that prints the multiplication table up to 5 × 5, formatted as a 5-by-5 grid (with each entry in a column of width 4).
Expected layout: 1 2 3 4 5 2 4 6 8 10 ...
14. [5 marks]
Write a program that asks the user to enter test marks one at a time, ending with -1. The program then prints (a) the number of marks entered, (b) the average mark, and (c) the highest mark. (Hint: sentinel-controlled while loop.)
