Question 1 — Boolean expression
What is the value of (5 > 3) and (10 < 5)?
Solution:
5 > 3 → True; 10 < 5 → False. True and False → False.
Question 2 — Tracing if/elif
What is printed?
x = 75 if x >= 90: print("A") elif x >= 80: print("B") elif x >= 70: print("C") else: print("F")
Solution:
75 fails >=90 and >=80 but passes >=70. Print "C" and exit the chain.
Question 3 — Loop sum
What is total after this loop?
total = 0 for i in range(1, 6): total += i print(total)
Solution:
range(1, 6) yields 1, 2, 3, 4, 5. Sum = 1+2+3+4+5 = 15.
Question 4 — Logic with not
What is not (5 == 5)?
Solution:
5 == 5 → True. not True → False.
Question 5 — Off-by-one
This loop is supposed to print numbers 1 through 10. What's wrong?
i = 1 while i < 10: print(i) i += 1
Solution:
The condition i < 10 stops at i=9. Fix: i <= 10. Classic off-by-one error.
Question 6 — Nested loop count
How many "*" characters are printed?
for i in range(3): for j in range(4): print("*", end="")
Solution:
Outer runs 3 times; inner runs 4 times each: 3 × 4 = 12.
Question 7 — Chained comparison
For x = 7, is 1 < x < 10 True or False?
Solution:
Python allows chained comparisons. 1 < 7 AND 7 < 10 are both True, so the whole expression is True.
Question 8 — Identify the bug
What is wrong with this check? if x == 1 or 2:
Solution:
Python evaluates this as (x == 1) or 2. The second operand 2 is truthy on its own, so the whole expression is always True. Correct form: x == 1 or x == 2, or x in (1, 2).
Question 9 — While loop trace
What is the final printed value of n?
n = 1 while n < 100: n = n * 2 print(n)
Solution:
n doubles: 1 → 2 → 4 → 8 → 16 → 32 → 64 → 128. At n=128, 128 < 100 is False, loop exits. Print 128.
Question 10 — Short-circuit evaluation
Does this line raise an error if y is 0?
if y != 0 and 10 / y > 2: print("big")
Solution:
Short-circuit evaluation: in A and B, if A is false (here y != 0 is False), B is never evaluated. So 10/y is skipped and no error occurs.
Question 11 — Counting evens
Write the one-line condition that checks whether an integer n is even. (Type just the Boolean expression.)
Solution:
n % 2 == 0. The remainder when dividing by 2 is 0 exactly when n is even.
Question 12 — De Morgan's law
Which expression is equivalent to not (x > 5 and y > 5)?
Solution:
De Morgan's law: not (A and B) = (not A) or (not B). So not (x > 5 and y > 5) = x <= 5 or y <= 5.
