Part A: Knowledge & Understanding [12 marks]
1. [3 marks]
Give the value AND the data type of each expression.
  1. 3 + 4 / 2
  2. "3" * 4
  3. 17 // 5
  4. bool("False")
2. [3 marks]
For each variable name, state whether it is valid in Python. If invalid, explain why.
  1. total_score
  2. 2nd_place
  3. _temp
  4. final-grade
  5. print
3. [3 marks]
What is the output of:
price = 19.99 qty = 3 total = price * qty print(f"Total: ${total:.2f}")
4. [3 marks]
Identify the data type that should be used to represent each:
  • The age of a student
  • The student's first name
  • Whether the student has paid their fee
  • The student's GPA
Part B: Thinking & Investigation [12 marks]
5. [4 marks]
Find and fix the bug(s). This program should print the user's age plus 10. There is at least one bug. Rewrite it correctly.
age = input("Enter your age: ") print("Next year you will be", age + 10)
6. [4 marks]
Trace this program. What is the final value of each variable, and what is printed?
a = 7 b = 4 c = a + b a = a * 2 b = c - a print(a, b, c)
7. [4 marks]
A school cafeteria sells sandwiches for $5 each. Customers receive a 10% discount when they buy 5 or more. Write a Python expression (just the arithmetic, no if needed) that gives the total cost for buying exactly n = 6 sandwiches at full price first, then state what the discounted total is. Show your work.
Part C: Communication [12 marks]
8. [4 marks]
Explain in your own words the difference between print() and return. Give a small example (1-2 lines) of when you would use each.
9. [4 marks]
Below is a peer's code. It works, but list four specific style issues and explain why each matters.
a=input("Bill:") b=float(a) c=b*0.13 d=b+c print(d)
10. [4 marks]
Add a header comment, meaningful variable names, and at least 2 inline comments to this program so a future reader can understand it without running it. You may also reformat for readability. Submit the rewritten version.
x=float(input()) y=x*5/9-32*5/9 print(y)
(Hint: this program converts a Fahrenheit temperature to Celsius.)
Part D: Application [12 marks]
11. [4 marks]
Write a complete Python program that asks the user for the length and width of a rectangle in metres and prints the area in square metres, rounded to 2 decimals. Include input prompts and friendly output.
12. [4 marks]
Write a program that asks the user for the total cost of a meal and the tip percent (e.g., 15), then prints both the tip amount and the final total. Format both as currency with two decimal places.
13. [4 marks]
Write a program that asks the user for a number of seconds (an integer), then prints the equivalent in hours, minutes, and seconds. Example: 3725 seconds becomes 1 hours, 2 minutes, 5 seconds.
Hint: 3600 sec = 1 hour. Use // and %.
