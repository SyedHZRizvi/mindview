🔍 Unit 1: Introduction to Programming — Pre-Unit Diagnostic

Assessment FOR Learning — Teacher Feedback
📋 Not Graded — Descriptive Feedback Only
Purpose: Since ICS3U has no formal prerequisite, your teacher uses this to find out what you already know about computers, basic logic, and arithmetic. Be honest — there is no "wrong" answer. Detailed responses help your teacher help you.
Question 1 — Prior experience
Have you written any code before (any language, any environment — Scratch, block-based, web, Roblox Studio, anything)? If yes, briefly describe one project you remember.
Question 2 — Basic arithmetic
Compute each by hand (no calculator).
  1. 247 ÷ 8 = quotient ___, remainder ___
  2. 3 + 4 × 5 = ___
  3. (3 + 4) × 5 = ___
  4. 25 = ___
Question 3 — Following instructions precisely
Read these instructions exactly and produce the final value of x.
START with x = 4 DOUBLE x ADD 3 DOUBLE the result WHAT IS x?
Question 4 — Logic in plain English
A movie theatre charges $12 for adults and $8 for children. A "child" is someone under 13. Write the rule that decides the ticket price for one customer in plain English, using "if" and "else".
Question 5 — Decomposition
Imagine you must write a program that takes 3 test marks and reports the average. List the high-level steps the program will perform, in order, in plain English.
Question 6 — Pattern recognition
What is the next number in each sequence? Briefly explain the pattern.
  1. 2, 4, 6, 8, ___
  2. 1, 2, 4, 8, ___
  3. 1, 4, 9, 16, ___
  4. 2, 6, 12, 20, ___
Question 7 — Vocabulary
In your own words, what is the difference between hardware and software? Give one example of each.
Question 8 — Comfort self-check
Rate yourself 1-5 (1=none, 5=very confident) on each, plus a one-sentence reason.
  • Typing on a keyboard.
  • Saving and finding a file on a computer.
  • Basic algebra (solve 2x + 3 = 11).
  • Following step-by-step instructions exactly.
  • Reading carefully and noticing small differences.
Question 9 — Reflection
What is one thing you are excited to learn this term, and one thing you are nervous about?
