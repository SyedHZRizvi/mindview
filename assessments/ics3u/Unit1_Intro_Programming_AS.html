Question 1 — Identify the type
What is the type of the value 3.14?
Solution:
Any number with a decimal point is a float. Whole numbers like 17 are int; text in quotes is str; only True/False are bool.
Question 2 — Type conversion
What is the output of:
x = "5" y = 2 print(int(x) + y)
Solution:
int("5") converts the string to the integer 5. Then 5 + 2 = 7. Without int(), "5" + 2 would raise TypeError.
Question 3 — Operator precedence
What does this expression evaluate to: 2 + 3 * 4?
Solution:
Multiplication binds tighter than addition. 3 * 4 = 12, then 2 + 12 = 14. If you wanted 20, you would parenthesise: (2 + 3) * 4.
Question 4 — Floor division and modulo
What does the following print?
x = 17 print(x // 5, x % 5)
Solution:
// is integer division: 17 // 5 = 3. % is remainder: 17 % 5 = 2. Output: 3 2.
Question 5 — F-string formatting
What is the output of:
total = 12.345 print(f"Total: ${total:.2f}")
Solution:
The format specifier .2f means fixed-point with 2 decimal places. 12.345 rounds to 12.35. Output: Total: $12.35.
Question 6 — input() returns
After x = input("Age: "), what is the type of x when the user types 17?
Solution:
input() always returns a string. To use it as a number, wrap it: int(input(...)) or float(input(...)). This is the most common beginner bug.
Question 7 — Identifier rules
Which of these is NOT a valid Python variable name?
Solution:
A variable name may not start with a digit. 2score is invalid. The others all start with a letter or underscore, so they are fine.
Question 8 — Concatenation vs addition
What is the output of:
a = "5" b = "3" print(a + b)
Solution:
Both a and b are strings. The + operator on strings is concatenation: "5" + "3" is "53", not 8.
Question 9 — Exponent operator
What is 2 ** 5?
Solution:
** is exponentiation. 2 ** 5 = 2 * 2 * 2 * 2 * 2 = 32. (Note: ^ is bitwise XOR in Python, NOT exponent.)
Question 10 — What does a comment do
Which best describes the role of a Python comment (starting with #)?
Solution:
Comments are for humans. The interpreter skips them entirely. They cost nothing at runtime and pay for themselves the first time someone re-reads the code.
Question 11 — Predict output
What does this program print?
name = "Ada" age = 17 print("Name:", name, "Age:", age)
Solution:
print with multiple comma-separated arguments inserts a space between each. Output: Name: Ada Age: 17.
Question 12 — Identify a runtime error
Which of these will raise a runtime error?
Solution:
int("hello") raises ValueError: "hello" has no integer interpretation. "3" + "4" gives "34" (no error). 10 / 2 gives 5.0. bool(0) gives False.
