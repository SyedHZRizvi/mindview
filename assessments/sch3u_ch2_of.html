Part A: Knowledge & Understanding [15 marks]
Question 1 [3 marks]
Classify each reaction (synthesis, decomposition, single displacement, double displacement, combustion, neutralization):
(a) \(2\text{Mg} + \text{O}_2 \rightarrow 2\text{MgO}\); (b) \(\text{C}_2\text{H}_6 + \tfrac{7}{2}\text{O}_2 \rightarrow 2\text{CO}_2 + 3\text{H}_2\text{O}\); (c) \(\text{Pb(NO}_3)_2 + 2\text{KI} \rightarrow \text{PbI}_2 + 2\text{KNO}_3\).
Question 2 [3 marks]
Balance: \(\text{Al} + \text{O}_2 \rightarrow \text{Al}_2\text{O}_3\). State the sum of all coefficients.
Solution:
4Al + 3O₂ → 2Al₂O₃. Sum = 4+3+2 = 9.
Question 3 [3 marks]
Write the balanced molecular equation for the reaction between aqueous lead(II) nitrate and aqueous sodium iodide.
Question 4 [3 marks]
Define: (a) spectator ion, (b) net ionic equation, (c) activity series.
Question 5 [3 marks]
Which of the following is the net ionic equation for HCl(aq) + KOH(aq) → KCl(aq) + H₂O(l)?
Solution:
(b) — spectator ions K⁺ and Cl⁻ are removed.

Question 15 [4 marks]

Complete Answer Key

Q1. (a) synthesis; (b) combustion; (c) double displacement.

Q2. 4Al + 3O₂ → 2Al₂O₃. Sum = 9.

Q3. Pb(NO₃)₂(aq) + 2NaI(aq) → PbI₂(s) + 2NaNO₃(aq).

Q4. (a) Spectator ion = ion present unchanged on both sides. (b) Net ionic eq. = eq. after removing spectators; shows actual chemistry. (c) Activity series = list of metals ranked by reactivity; metal higher in the list displaces those lower from solution.

Q5. (b).

Q6. (a) Mg above Zn — yes: Mg(s) + Zn(NO₃)₂(aq) → Mg(NO₃)₂(aq) + Zn(s). (b) Cu above Ag — yes: Cu(s) + 2AgNO₃(aq) → Cu(NO₃)₂(aq) + 2Ag(s). (c) Ag below Zn — no reaction.

Q7. Molecular: BaCl₂(aq) + Na₂SO₄(aq) → BaSO₄(s) + 2NaCl(aq). Complete ionic: Ba²⁺ + 2Cl⁻ + 2Na⁺ + SO₄²⁻ → BaSO₄(s) + 2Na⁺ + 2Cl⁻. Net ionic: Ba²⁺(aq) + SO₄²⁻(aq) → BaSO₄(s).

Q8. Equal moles strong acid + strong base → exactly neutralized → pH ≈ 7 (technically 7.0 if temperature 25 °C).

Q9. All possible products (NaNO₃, KCl) are soluble. Net ionic equation has nothing left — no actual reaction.

Q10. Synthesis: A + B → AB (e.g., 2H₂ + O₂ → 2H₂O). Decomposition: AB → A + B (e.g., 2H₂O₂ → 2H₂O + O₂). Synthesis forms bonds; decomposition breaks them.

Q11. Limited O₂ → not enough to convert all C to CO₂ → CO and/or soot form: 2CH₄ + 3O₂ → 2CO + 4H₂O. CO binds hemoglobin ~250× more strongly than O₂, preventing O₂ transport.

Q12. State symbols tell whether species is solid, liquid, gas, or in solution. AgCl is INSOLUBLE — it cannot be aqueous; NaNO₃ is highly soluble — it cannot be solid in this context.

Q13. "An ionic reaction occurs in aqueous solution when a precipitate (insoluble product), a gas, or a weak electrolyte (e.g., water) is formed."

Q14. Ag⁺(aq) + Cl⁻(aq) → AgCl(s) [white]; Ag⁺(aq) + I⁻(aq) → AgI(s) [pale yellow]. The Cl⁻ vs I⁻ ions can be distinguished by precipitate colour and texture.

Q15. CaCO₃(s) + 2HCl(aq) → CaCl₂(aq) + H₂O(l) + CO₂(g) (also a decomposition of carbonic acid). Mg(OH)₂(s) + 2HCl(aq) → MgCl₂(aq) + 2H₂O(l). Both neutralize H⁺.

Q16. 2H₂(g) + O₂(g) → 2H₂O(l) (combustion). In the battery: Pb(s) + PbO₂ + 2H₂SO₄ → 2PbSO₄(s) + 2H₂O (redox). Hydrogen forms by side reaction in overcharge.

Q17. Al₂(SO₄)₃(aq) + 3Ca(OH)₂(aq) → 2Al(OH)₃(s) + 3CaSO₄(s) (both precipitate). NIE: Al³⁺(aq) + 3OH⁻(aq) → Al(OH)₃(s) (the alum coagulant).
